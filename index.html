🟢 เข้าสู่ระบบสำเร็จพร้อมใช้งาน
💡 วิธีสร้าง GitHub Token ภายใน 1 นาที:
1. เข้า GitHub ➔ Settings ➔ Developer settings ➔ Personal access tokens (classic)
2. กด Generate new token แล้วติ๊กถูกช่อง repo และ workflow
3. คัดลอก Token (ขึ้นต้นด้วย ghp_...) มาวางในช่องด้านบนได้เลย!

สร้างที่เก็บข้อมูลใหม่และการตั้งค่า Windows

ตั้งค่าเวอร์ชัน Windows และระยะเวลาหมดอายุสูงสุดก่อนสร้างที่เก็บข้อมูลโดยอัตโนมัติ

เลือกโหมดการแสดงผลและโควต้าผู้วิ่ง:
🔒 ที่เก็บข้อมูลส่วนตัว
ระงับอย่างปลอดภัย
  • จำกัดปริมาณการใช้งาน: 2,000 นาที/เดือน
  • ระบบรักษาความปลอดภัย: เสถียรและไม่มีการระงับการใช้งาน
🌐 คลังข้อมูลสาธารณะ
มีแนวโน้มที่จะเกิดการแขวนลอย
  • ขีดจำกัดเวลาใช้งาน: ไม่จำกัด (สูงสุด 6 ชั่วโมงต่อครั้ง)
  • ความเสี่ยง: จะถูกระงับหากถูกตรวจพบโดยสาธารณะ
⚙️ การตั้งค่าสภาพแวดล้อม YML และตัวจับเวลาการลบฐานข้อมูล
📢 การตั้งค่า Discord Webhooks (ส่งข้อมูลสถานะ & รหัสผ่านเข้าเครื่อง)
Discord Webhook
📡 Log Webhook: จะส่งบันทึกสถานะการเริ่มระบบ การเปิดพอร์ต RDP และข้อความแจ้งเตือนต่างๆ ไปยัง Discord ช่องที่คุณเลือก
🔑 Info Webhook: จะส่งข้อมูลเชื่อมต่อ RDP ที่พร้อมใช้งาน (Host, Port, ชื่อผู้ใช้ และรหัสผ่าน) ไปยัง Discord ช่องที่คุณเลือก
